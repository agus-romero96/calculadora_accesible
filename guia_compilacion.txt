GUÍA DE COMPILACIÓN: CALCULADORA ACCESIBLE
==========================================

Cómo generar el ejecutable y el instalador de Windows.


1. REQUISITOS (una sola vez)
----------------------------

- Python 3.12 para Windows.
- Inno Setup 6 (solo para el instalador): https://jrsoftware.org/isinfo.php
- Dependencias de desarrollo (incluyen las de la calculadora, pytest y cx_Freeze):

      pip install -r requirements-dev.txt


2. CAMBIAR LA VERSIÓN
---------------------

La versión se define en UN SOLO lugar: el archivo _version.py

      __version__ = "1.1.0"

De ahí la toman el título de la ventana, el ejecutable (setup.py) y el
instalador (compilar.py se la pasa a Inno Setup). No hay que tocar
setup_script.iss.

Antes de publicar, mueva los cambios de la sección [Sin publicar] del
CHANGELOG.md a una sección con el número de versión y la fecha.


3. COMPILAR
-----------

En la carpeta del proyecto:

      python compilar.py

El script hace cuatro pasos y se detiene en el primer fallo:

  1. Ejecuta las pruebas (pytest).
  2. Compila el ejecutable con cx_Freeze en build\CalculadoraAccesible\
  3. Ejecuta el .exe compilado con --autoprueba: calcula un caso de cada
     motor sin abrir la ventana. Si falla, al empaquetado le falta algún
     módulo (revise la lista "excludes" de setup.py).
  4. Genera el instalador en Output\setup-calculadora-accesible-v<versión>.exe

Opciones:

      python compilar.py --sin-pruebas      omite el paso 1
      python compilar.py --sin-instalador   omite el paso 4
      python compilar.py --salida CARPETA   guarda el instalador en otra carpeta

ATENCIÓN: si no cambió la versión, el instalador nuevo reemplaza al anterior
con el mismo nombre en Output\. Guarde una copia si ya lo distribuyó.


PUBLICAR: cree en GitHub una Release con la etiqueta vX.Y.Z y adjunte el
instalador con su nombre exacto (setup-calculadora-accesible-vX.Y.Z.exe).
Las calculadoras instaladas la detectan y se actualizan solas (actualizador.py).
El repositorio debe ser público, y la Release no debe ser "pre-release" ni
borrador. Detalles en el README, "Publicar una versión".


4. COMPROBAR EL EJECUTABLE A MANO
---------------------------------

      build\CalculadoraAccesible\CalculadoraAccesible.exe --autoprueba informe.txt

Escribe el resultado en informe.txt (el programa no tiene consola) y
termina con código 0 si todo está bien.


5. NOTAS
--------

- El AppId de setup_script.iss NO debe cambiarse: es lo que permite que una
  versión nueva actualice a la ya instalada en lugar de instalarse aparte.
- setup.py excluye librerías que SymPy importa de forma opcional (numpy,
  scipy, matplotlib, numba/llvmlite, etc.). La calculadora no las usa y
  ocupaban más de 150 MB. Si en el futuro se usa alguna, quítela de "excludes".
- Las carpetas build\, dist\ y Output\ no se guardan en git.
