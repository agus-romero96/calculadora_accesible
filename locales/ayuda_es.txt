MANUAL DE USUARIO: CALCULADORA CIENTÍFICA ACCESIBLE
===================================================

1. ¿QUÉ ES ESTA HERRAMIENTA?
   Es una calculadora avanzada que funciona como un chat.
   Usted escribe una orden matemática en el cuadro de arriba,
   presiona una combinación de teclas, y el resultado aparece
   aquí abajo, listo para ser leído.

2. FLUJO DE TRABAJO (CÓMO USARLA)
   Paso A: Escriba su fórmula (ej: 2+2) en la entrada.
   Paso B: Elija qué hacer (Calcular, Derivar, Integrar).
           Puede usar el menú o los atajos de teclado.
   Paso C: El foco saltará automáticamente a este cuadro
           para leerle el resultado paso a paso.

3. ATAJOS DE TECLADO (MEMORIZAR ESTOS)
   [Ctrl + Enter]     : CALCULAR (Aritmética básica, Ecuaciones, Sistemas).
   [Ctrl + S]         : SIMPLIFICAR una expresión.
   [Ctrl + F]         : FACTORIZAR un polinomio.
   [Ctrl + D]         : DERIVAR una función.
   [Ctrl + Mayús + D] : DERIVADA de orden N.
   [Ctrl + I]         : INTEGRAR una función.
   [Ctrl + Mayús + I] : INTEGRAL DEFINIDA entre dos límites.
   [Ctrl + L]         : Calcular LÍMITE.
   [Ctrl + T]         : RECTA TANGENTE y normal en un punto.
   [Ctrl + Mayús + X] : EXTREMOS e intervalos de crecimiento.
   [Ctrl + Mayús + T] : POLINOMIO DE TAYLOR de orden n en un punto.
   [Ctrl + J]         : DERIVADA IMPLÍCITA dy/dx de una curva F(x, y).
   [Ctrl + Mayús + R] : ECUACIÓN DIFERENCIAL (con condición inicial opcional).
   [Ctrl + R]         : RESOLVER una ecuación o inecuación.
   [Ctrl + G]         : Resolver SISTEMA por Gauss-Jordan.
   [Ctrl + M]         : MATRIZ INVERSA por cofactores.
   [Ctrl + K]         : DETERMINANTE de una matriz por cofactores.
   [Ctrl + Retroceso] : LIMPIAR pantalla para empezar de cero.
   [Ctrl + Mayús + C] : COPIAR el resultado.
   [Ctrl + E]         : EXPORTAR el resultado a un archivo.
   [Ctrl + H]         : Ver el HISTORIAL de operaciones.
   [Ctrl + Mayús + P] : Mostrar u ocultar el PASO A PASO.
   [F1]               : Ver esta ayuda.
   [Alt]              : Acceder a la barra de menús.
   Sistemas 2x2 por sustitución, igualación o reducción:
   menú Álgebra, submenú 'Sistema 2x2 por método clásico'.

   Si un cálculo tarda, se abre el diálogo 'Calculando'.
   Puede pulsar Cancelar para detenerlo: el cálculo se interrumpe
   de inmediato y deja de usar el procesador.

4. GUÍA DE ESCRITURA (SINTAXIS)
   Para que la calculadora le entienda, escriba así:

   * Multiplicación: Puede usar el asterisco o escribir
     el número pegado: 2*x, 2x, 3sin(x) y 2(x+1) son válidos.
     IMPORTANTE: entre una variable y una función use
     siempre el asterisco.
     CORRECTO: x*sin(x)     INCORRECTO: xsin(x)

   * Potencias: Use el sombrero (^) o doble asterisco (**).
     Ejemplo: x^2  o  x**2

   * Funciones: Use paréntesis siempre.
     Ejemplo: sin(x), cos(x), ln(x), sqrt(x)

   * Constantes matemáticas:
     Escriba 'pi' para el número Pi.
     Escriba 'e' para el número de Euler.
     Escriba 'oo' (doble letra o) para Infinito.

   * Matrices (para la inversa): una fila por línea,
     con los números separados por espacios. Ejemplo:
       1 2
       3 4

5. EJEMPLOS PRÁCTICOS
   - Calcular: Escriba '(2+3)*4 - 2^2'. Pulse Ctrl+Enter.
     El paso a paso sigue la jerarquía de las operaciones: primero
     lo que hay entre paréntesis, después las potencias, las
     multiplicaciones y divisiones, y por último sumas y restas,
     una operación por paso con su regla y su cuenta.
   - Factorizar: Escriba 'x^2 - 5*x + 6'. Cada caso (factor común,
     diferencia de cuadrados, trinomios, Ruffini...) explica sus
     cuentas, y al final se comprueba multiplicando los factores.
   - Derivar: Escriba '3*x^2 + 5'. Pulse Ctrl+D.
     Cada regla se explica en el mismo orden, una línea por parte:
     "Regla" (el enunciado general), "En este caso" (qué parte
     de su expresión es cada pieza de la regla), las cuentas
     (por ejemplo 2 - 1 = 1) y "Queda" (cómo queda la expresión).
   - Integrar: Escriba 'sin(x)'. Pulse Ctrl+I.
     Los pasos siguen el mismo orden que en las derivadas, y en
     el cambio de variable se dice qué parte es u y cuál es du.
     Con un cociente de polinomios, como '1/(x^2-1)', se usan
     fracciones parciales: se dividen los polinomios si hace
     falta, se factoriza el denominador, se plantean los
     coeficientes A, B..., se hallan sustituyendo las raíces e
     igualando coeficientes, y se integra cada fracción simple
     (logaritmos, potencias y arcotangentes).
     Con una raíz como sqrt(4 - x^2), sqrt(x^2 + 4) o sqrt(x^2 - 9)
     se usa la sustitución trigonométrica (x = a*sin, a*tan o
     a*sec de t): se calcula dx, la raíz desaparece con la
     identidad pitagórica, se integra en t y se vuelve a x con un
     triángulo rectángulo, cuyos lados salen por Pitágoras.
   - Integral definida: Escriba 'x^2'. Pulse Ctrl+Mayús+I.
     Límite inferior: 0. Límite superior: 1. Resultado: 1/3.
     Los límites pueden ser expresiones (pi/2) o infinito (oo, -oo).
     Si un límite es infinito o la función no es continua en el
     intervalo (por ejemplo 1/x^2 entre -1 y 1), es una integral
     impropia: la calculadora la divide en tramos, calcula los
     límites necesarios y le dice si converge o diverge.
   - Recta tangente y normal: Escriba 'x^3 - 2*x'. Pulse Ctrl+T.
     Punto x0: 1. Resultado: tangente y = x - 2, normal y = -x.
     Primero se calcula el punto (1, f(1)) con sus cuentas, después
     la derivada paso a paso, la pendiente m = f'(1), la ecuación
     punto-pendiente despejada, la pendiente de la normal -1/m y,
     al final, la comprobación. Si la tangente es horizontal, la
     normal es vertical (x = x0), y al revés.
   - Extremos y crecimiento: Escriba 'x^3 - 3*x'. Pulse Ctrl+Mayús+X.
     Resultado: máximo local en x = -1 (f(-1) = 2), mínimo local en
     x = 1 (f(1) = -2); creciente en (-∞, -1) ∪ (1, ∞) y
     decreciente en (-1, 1). Se calcula el dominio, la derivada
     paso a paso, los puntos críticos (f'(x) = 0), una tabla con
     el signo de f' en cada intervalo, factor a factor, y los
     criterios de la primera y la segunda derivada.
   - Polinomio de Taylor: Escriba 'exp(x)'. Pulse Ctrl+Mayús+T.
     Orden: 3. Punto x0: 0. Resultado: P_3(x) = 1 + x + x^2/2 + x^3/6.
     Se calcula cada derivada a partir de la anterior, y en cada
     término su valor en x0, el factorial (3! = 1*2*3 = 6) y el
     coeficiente. Con x0 distinto de 0 el polinomio se escribe en
     potencias de (x - x0), por ejemplo (x - 4)/4.
   - Derivada implícita: Escriba 'x^2 + y^2 = 25'. Pulse Ctrl+J.
     Resultado: dy/dx = -x/y. Se derivan los dos lados respecto a
     x; cada vez que se deriva algo con y, la regla de la cadena
     añade el factor y' (en x*y, regla del producto). Al final se
     despeja y': pasar términos, sacar y' factor común, dividir y
     simplificar.
   - Ecuación diferencial: Escriba "y' = 2*x*y" (también vale
     dy/dx). Pulse Ctrl+Mayús+R. Resultado: y = C*exp(x^2).
     Para una condición inicial, escríbala detrás con una coma:
     "y' = 2*x*y, y(0) = 3" da y = 3*exp(x^2). Primero se dice
     el tipo de ecuación. Si es separable, y' = g(x)*h(y): se
     separan las variables, se integra cada lado con el paso a
     paso de Integrar, se despeja y (la constante C absorbe los
     números, los signos y exp(C)) y se ven las soluciones
     constantes, h(y) = 0. Si es y' = F(a*x + b*y + c), el cambio
     u = a*x + b*y + c la hace separable. Al final se comprueba
     la solución derivándola. Los demás tipos los resuelve SymPy,
     sin pasos, con una nota.
   - Límite: Escriba 'sin(x)/x'. Pulse Ctrl+L.
     Variable: x. Tendencia: 0.
     Para un límite lateral escriba la tendencia con + o -,
     por ejemplo 0+ (por la derecha) o 0- (por la izquierda).
     Para infinito escriba oo, o -oo para menos infinito.
     El paso a paso empieza siempre sustituyendo y diciendo qué
     forma sale (0/0, infinito entre infinito...); después cada
     transformación tiene su regla y sus cuentas.
   - Ecuación o inecuación: Escriba una línea con un signo
     =, <, >, <= o >=, por ejemplo 'x^2 - 5*x + 6 = 0' o
     'x^2 - 4 <= 0'. Pulse Ctrl+R (o Ctrl+Enter).
     Ecuaciones de primer y segundo grado: se despeja la incógnita
     o se calcula el discriminante con sus cuentas y se aplica la
     factorización o la fórmula general.
     Ecuaciones con fracciones (racionales): primero los valores
     que anulan un denominador (prohibidos), después se multiplica
     por el MCM y al final se descartan las raíces extrañas.
     Inecuaciones: al multiplicar o dividir por un número negativo
     se avisa de que el sentido se invierte; en las de segundo
     grado, una tabla de signos explica cada intervalo línea a
     línea. La solución se escribe como desigualdad y como
     intervalo, por ejemplo: x < -2 o x > 2, es decir,
     (-∞, -2) ∪ (2, ∞). Siempre se comprueba sustituyendo en la
     ecuación original.
   - Determinante: Escriba la matriz, una fila por línea:
       2 0 1
       1 3 2
       1 0 4
     Pulse Ctrl+K. Resultado: det(A) = 21. Se desarrolla por la
     fila o columna con más ceros (aquí la columna 2): los ceros
     no aportan nada y su menor no hace falta. Cada menor y cada
     cofactor llevan sus cuentas. En una 4x4, cada menor 3x3 se
     desarrolla en sus propios pasos, con otras letras (b, N, D)
     para no confundirlo con la matriz A.
   - Sistema 2x2: Escriba dos líneas:
       x + y = 10
       x - y = 2
     Luego pulse Ctrl+Enter.
     En Álgebra el resultado va primero. Después, cada ecuación se
     resuelve a la vista (quitar paréntesis, pasar términos al otro
     lado cambiando de signo, dividir), cada operación de fila de
     Gauss-Jordan muestra la cuenta de cada número, y al final se
     comprueba la solución en las ecuaciones originales.

6. SOLUCIÓN DE PROBLEMAS
   - ¿Le pregunta por variables? Si escribe 'x + y', el sistema
     le preguntará con cuál desea trabajar. Use las flechas
     para elegir en el diálogo y pulse Enter.
   - ¿Error de Sintaxis? Verifique que cerró todos los paréntesis
     y que usó '*' entre una variable y una función.
   - ¿Dice que hay un cálculo en curso? Espere a que termine,
     o pulse Cancelar en el diálogo 'Calculando'.

7. COPIAR Y EXPORTAR RESULTADOS (menú Resultado)
   [Ctrl + Mayús + C] : Copiar solo el resultado (ej: x = 6, y = 4).
   [Ctrl + Mayús + A] : Copiar la explicación completa.
   [Ctrl + Mayús + L] : Copiar el resultado en LaTeX.
   [Ctrl + Mayús + M] : Copiar el resultado en MathML.
   [Ctrl + E]         : Exportar a un archivo. Formatos:
     - HTML con fórmulas MathML: se abre en el navegador y el
       lector de pantalla puede leer y explorar las fórmulas.
     - Texto plano, Markdown, documento LaTeX y JSON.
   Elija el formato en la lista 'Tipo' del diálogo Guardar.

8. IDIOMA
   El menú 'Idioma / Language' cambia el idioma de la
   calculadora (español o inglés). Los resultados nuevos se
   muestran en el idioma elegido, y se recuerda al reiniciar.

9. HISTORIAL DE OPERACIONES (menú Historial)
   Cada cálculo correcto se guarda en el historial (hasta 200
   operaciones). Se conserva al cerrar la calculadora; para
   borrarlo, use Historial > Borrar historial.
   [Ctrl + H]         : Ver el historial. Es una lista con la
                        operación más reciente primero.
     - Enter          : Mostrar esa operación completa. Vuelve a ser
                        el resultado actual: puede copiarlo o exportarlo.
     - Alt + U        : Usar entrada: copia la expresión al cuadro de
                        entrada para modificarla y calcular de nuevo.
     - Suprimir       : Eliminar esa operación del historial.
     - Escape         : Cerrar el historial.
   [Ctrl + Mayús + E] : Exportar todo el historial a un archivo
                        (mismos formatos que un resultado).

10. OPCIONES (menú Opciones)
   Las opciones se recuerdan al reiniciar la calculadora.
   [Ctrl + Mayús + P] : Mostrar el paso a paso (casilla marcada) o
                        solo el resultado (casilla sin marcar).
     - Con el paso a paso, cada resultado trae la explicación
       completa, como siempre.
     - Sin el paso a paso, se muestra solo el resultado, la
       operación y los datos (entrada, variable, tendencia...).
       Las soluciones de un sistema y las filas de una matriz
       van una por línea.
     - Al cambiar la opción, el resultado actual se vuelve a
       mostrar en el nuevo modo: así puede ver el paso a paso de
       un resultado sin calcularlo otra vez.
     - El historial y la exportación siempre guardan la
       explicación completa, y Ctrl + Mayús + A la copia.

11. ACTUALIZACIONES
   Al abrirse, la calculadora comprueba si hay una versión nueva
   (solo si tiene conexión a internet; si no la hay, no dice nada).
   Si la hay, muestra sus novedades y le ofrece tres botones:
     - Actualizar ahora : descarga la versión nueva (con un diálogo
                          de progreso que puede cancelar), se cierra,
                          la instala y se vuelve a abrir. Windows le
                          pedirá permiso para instalarla.
     - Omitir esta versión : no volverá a ofrecerla al abrir.
     - Más tarde (o Escape) : se la ofrecerá la próxima vez.
   Para comprobarlo en cualquier momento: menú Ayuda,
   'Buscar actualizaciones'.
   Para que no lo compruebe al abrir, desmarque en el menú
   Opciones la casilla 'Buscar actualizaciones al iniciar'.
