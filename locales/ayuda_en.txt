USER MANUAL: ACCESSIBLE SCIENTIFIC CALCULATOR
=============================================

1. WHAT IS THIS TOOL?
   It is an advanced calculator that works like a chat.
   You type a math command in the box above,
   press a key combination, and the result appears
   down here, ready to be read.

2. WORKFLOW (HOW TO USE IT)
   Step A: Type your formula (e.g. 2+2) in the input box.
   Step B: Choose what to do (Calculate, Differentiate, Integrate).
           You can use the menu or the keyboard shortcuts.
   Step C: Focus moves automatically to this box
           so the result is read to you step by step.

3. KEYBOARD SHORTCUTS (MEMORIZE THESE)
   [Ctrl + Enter]     : CALCULATE (basic arithmetic, equations, systems).
   [Ctrl + S]         : SIMPLIFY an expression.
   [Ctrl + F]         : FACTOR a polynomial.
   [Ctrl + D]         : DIFFERENTIATE a function.
   [Ctrl + Shift + D] : Nth-order DERIVATIVE.
   [Ctrl + I]         : INTEGRATE a function.
   [Ctrl + Shift + I] : DEFINITE INTEGRAL between two limits.
   [Ctrl + L]         : Calculate a LIMIT.
   [Ctrl + T]         : TANGENT and normal LINE at a point.
   [Ctrl + Shift + X] : EXTREMA and intervals of increase.
   [Ctrl + Shift + T] : TAYLOR POLYNOMIAL of order n at a point.
   [Ctrl + R]         : SOLVE an equation or inequality.
   [Ctrl + G]         : Solve a SYSTEM by Gauss-Jordan.
   [Ctrl + M]         : INVERSE MATRIX by cofactors.
   [Ctrl + Backspace] : CLEAR the screen to start over.
   [Ctrl + Shift + C] : COPY the result.
   [Ctrl + E]         : EXPORT the result to a file.
   [Ctrl + H]         : View the calculation HISTORY.
   [Ctrl + Shift + P] : Show or hide the STEP-BY-STEP explanation.
   [F1]               : Show this help.
   [Alt]              : Open the menu bar.
   2x2 systems by substitution, equalization or elimination:
   Algebra menu, '2x2 system by classical method' submenu.

   If a calculation takes a while, the 'Calculating' dialog opens.
   You can press Cancel to stop it: the calculation is interrupted
   at once and stops using the processor.

4. WRITING GUIDE (SYNTAX)
   For the calculator to understand you, write like this:

   * Multiplication: Use the asterisk, or write the number
     right next to it: 2*x, 2x, 3sin(x) and 2(x+1) are valid.
     IMPORTANT: between a variable and a function always
     use the asterisk.
     CORRECT: x*sin(x)     INCORRECT: xsin(x)

   * Powers: Use the caret (^) or double asterisk (**).
     Example: x^2  or  x**2

   * Functions: Always use parentheses.
     Example: sin(x), cos(x), ln(x), sqrt(x)

   * Mathematical constants:
     Type 'pi' for the number Pi.
     Type 'e' for Euler's number.
     Type 'oo' (double letter o) for Infinity.

   * Matrices (for the inverse): one row per line,
     with the numbers separated by spaces. Example:
       1 2
       3 4

5. PRACTICAL EXAMPLES
   - Calculate: Type '(2+3)*4 - 2^2'. Press Ctrl+Enter.
     The steps follow the order of operations: first what is in
     parentheses, then powers, multiplications and divisions, and
     finally additions and subtractions, one operation per step
     with its rule and its arithmetic.
   - Factor: Type 'x^2 - 5*x + 6'. Each case (common factor,
     difference of squares, trinomials, synthetic division...)
     shows its arithmetic, and the factors are checked by
     multiplying them at the end.
   - Differentiate: Type '3*x^2 + 5'. Press Ctrl+D.
     Each rule is explained in the same order, one line per part:
     "Rule" (the general statement), "In this case" (which part
     of your expression is each piece of the rule), the arithmetic
     (for example 2 - 1 = 1) and "We get" (the resulting expression).
   - Integrate: Type 'sin(x)'. Press Ctrl+I.
     The steps follow the same order as for derivatives, and in a
     change of variable they say which part is u and which is du.
   - Definite integral: Type 'x^2'. Press Ctrl+Shift+I.
     Lower limit: 0. Upper limit: 1. Result: 1/3.
     The limits can be expressions (pi/2) or infinity (oo, -oo).
     If a limit is infinite or the function is not continuous on the
     interval (for example 1/x^2 from -1 to 1), it is an improper
     integral: the calculator splits it into parts, takes the
     necessary limits and tells you whether it converges or diverges.
   - Tangent and normal line: Type 'x^3 - 2*x'. Press Ctrl+T.
     Point x0: 1. Result: tangent y = x - 2, normal y = -x.
     First the point (1, f(1)) is calculated with its arithmetic,
     then the derivative step by step, the slope m = f'(1), the
     point-slope equation solved for y, the slope of the normal
     -1/m and, finally, the check. If the tangent is horizontal,
     the normal is vertical (x = x0), and vice versa.
   - Extrema and monotonicity: Type 'x^3 - 3*x'. Press Ctrl+Shift+X.
     Result: local maximum at x = -1 (f(-1) = 2), local minimum at
     x = 1 (f(1) = -2); increasing on (-oo, -1) U (1, oo) and
     decreasing on (-1, 1). It calculates the domain, the
     derivative step by step, the critical points (f'(x) = 0), a
     chart with the sign of f' on each interval, factor by
     factor, and the first and second derivative tests.
   - Taylor polynomial: Type 'exp(x)'. Press Ctrl+Shift+T.
     Order: 3. Point x0: 0. Result: P_3(x) = 1 + x + x^2/2 + x^3/6.
     Each derivative is calculated from the previous one, and for
     each term its value at x0, the factorial (3! = 1*2*3 = 6) and
     the coefficient. With x0 other than 0 the polynomial is written
     in powers of (x - x0), for example (x - 4)/4.
   - Limit: Type 'sin(x)/x'. Press Ctrl+L.
     Variable: x. Approaches: 0.
     For a one-sided limit, type the value followed by + or -,
     for example 0+ (from the right) or 0- (from the left).
     For infinity type oo, or -oo for minus infinity.
     The steps always start by substituting and saying which form
     appears (0/0, infinity over infinity...); then each
     transformation has its rule and its arithmetic.
   - Equation or inequality: Type one line with a sign
     =, <, >, <= or >=, for example 'x^2 - 5*x + 6 = 0' or
     'x^2 - 4 <= 0'. Press Ctrl+R (or Ctrl+Enter).
     Linear and quadratic equations: the unknown is isolated, or
     the discriminant is calculated with its arithmetic and the
     equation is factored or solved with the quadratic formula.
     Equations with fractions (rational): first the values that
     make a denominator 0 (excluded), then both sides are
     multiplied by the LCM, and finally extraneous roots are
     discarded.
     Inequalities: when multiplying or dividing by a negative
     number, it tells you the direction is reversed; quadratic
     inequalities use a sign chart explained interval by
     interval. The solution is written as inequalities and as
     intervals, for example: x < -2 or x > 2, that is,
     (-oo, -2) U (2, oo). It is always checked by substituting
     into the original equation.
   - 2x2 system: Type two lines:
       x + y = 10
       x - y = 2
     Then press Ctrl+Enter.
     In Algebra the result comes first. Then each equation is
     solved step by step (removing parentheses, moving terms to the
     other side with the opposite sign, dividing), each Gauss-Jordan
     row operation shows the arithmetic for every number, and the
     solution is checked in the original equations.

6. TROUBLESHOOTING
   - Does it ask you for a variable? If you type 'x + y', the program
     asks which one you want to work with. Use the arrow keys
     to choose in the dialog and press Enter.
   - Syntax error? Check that you closed all parentheses
     and used '*' between a variable and a function.
   - Does it say a calculation is in progress? Wait for it to finish,
     or press Cancel in the 'Calculating' dialog.

7. COPYING AND EXPORTING RESULTS (Result menu)
   [Ctrl + Shift + C] : Copy only the result (e.g. x = 6, y = 4).
   [Ctrl + Shift + A] : Copy the full explanation.
   [Ctrl + Shift + L] : Copy the result as LaTeX.
   [Ctrl + Shift + M] : Copy the result as MathML.
   [Ctrl + E]         : Export to a file. Formats:
     - HTML with MathML formulas: opens in the browser, and
       the screen reader can read and explore the formulas.
     - Plain text, Markdown, LaTeX document and JSON.
   Choose the format in the 'Save as type' list of the Save dialog.

8. LANGUAGE
   The 'Idioma / Language' menu changes the language of the
   calculator (Spanish or English). New results are shown in
   the chosen language, and the choice is remembered on restart.

9. CALCULATION HISTORY (History menu)
   Every successful calculation is saved in the history (up to 200
   calculations). It is kept when you close the calculator; to
   erase it, use History > Clear history.
   [Ctrl + H]         : View the history. It is a list with the
                        most recent calculation first.
     - Enter          : Show that calculation in full. It becomes the
                        current result again: you can copy or export it.
     - Alt + U        : Use input: puts the expression back in the input
                        box so you can edit it and calculate again.
     - Delete         : Remove that calculation from the history.
     - Escape         : Close the history.
   [Ctrl + Shift + E] : Export the whole history to a file
                        (same formats as a single result).

10. OPTIONS (Options menu)
   Options are remembered when you restart the calculator.
   [Ctrl + Shift + P] : Show the step-by-step explanation (box
                        checked) or only the result (box unchecked).
     - With the step-by-step explanation, every result includes
       the full explanation, as always.
     - Without it, only the result, the operation and its data
       (input, variable, approach value...) are shown. The
       solutions of a system and the rows of a matrix go one
       per line.
     - When you change the option, the current result is shown
       again in the new mode: this way you can see the steps of a
       result without calculating it again.
     - The history and exported files always keep the full
       explanation, and Ctrl + Shift + A copies it.

11. UPDATES
   When it opens, the calculator checks whether a new version is
   available (only if you are connected to the internet; if not,
   it says nothing). If there is one, it shows what's new and
   offers three buttons:
     - Update now       : downloads the new version (with a progress
                          dialog you can cancel), closes, installs it
                          and opens again. Windows will ask for
                          permission to install it.
     - Skip this version : it will not be offered again at startup.
     - Later (or Escape) : it will be offered next time.
   To check at any time: Help menu, 'Check for updates'.
   To stop checking at startup, uncheck 'Check for updates at
   startup' in the Options menu.
